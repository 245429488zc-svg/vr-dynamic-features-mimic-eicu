# Early ventilatory ratio (VR) dynamic features and hospital mortality in mechanically ventilated patients — analysis code

Code repository for the study **"Early ventilatory ratio features derived from repeated measurements and hospital mortality in mechanically ventilated patients: derivation and external validation"** (MIMIC-IV v3.1 derivation; eICU-CRD v2.0 external validation).

## Data access

This repository contains **no patient data**. MIMIC-IV v3.1 and eICU-CRD v2.0 are publicly available to credentialed users through PhysioNet (https://physionet.org), under the applicable data use agreements; the data may not be redistributed. Cohort construction builds on the **official MIMIC-IV derived tables** (generated by the public `mimic-code` repository) and the eICU-CRD tables, followed by study-specific Python processing (this repository).

Place the source/derived tables under `./raw_data/mimmc4/...` as indicated in the path constants at the top of each script, and run scripts from the repository root.

## Pipeline overview

| Stage | Scripts | What they define |
|---|---|---|
| 1. Cohort construction | `01_cohort_construction/build_pf_vr_analysis_data.py` | Adult ICU stays; invasive ventilation started within 24 h of ICU admission (official `ventilation` intervals, `InvasiveVent`); ABG–ventilator nearest-neighbor pairing within **±2 h**; paired P/F–VR points within **0–48 h of ICU admission**; physiologic range checks (P/F 30–700, PaCO2 10–150, minute ventilation 1–30 L/min, VR 0.2–10); hospital mortality from the derived admission flag |
| 2. Feature derivation | `01_cohort_construction/build_trajectory_48h.py` | Per-patient paired-point tables (0–48 h); eight VR summaries: **initial, last, mean, maximum, minimum, AUC (trapezoidal integration normalized by the observation span, i.e., time-weighted mean VR), delta (last − first), slope (linear-regression slope)**; observation span (first→last measurement interval) recorded per patient |
| 3. Covariates | `02_covariates/enhanced_covariates_analysis.py` | Temporal definitions of all adjustment variables (admission-level fixed characteristics; SOFA-24 h; first-day means/maxima/minima for vitals and laboratories; 0–48 h means for ventilator settings; P/F initial and minimum) — see Supplementary Table 5 of the manuscript |
| 4. Main analyses | `03_main_analyses/` | Table 2 (single-feature associations, fully adjusted logistic models); Table 3 (incremental value: ΔAUROC with DeLong test, category-free NRI with event/non-event components, IDI; harmonized reduced model transported unchanged to eICU); Table 4 (sensitivity analyses) |
| 5. Revision analyses | `04_revision_analyses/` | 48-h **landmark analysis** (`run_landmark_48h.py`); **included-vs-excluded comparison** (`make_supp_table3.py`); **standardized anchor-point analysis** — one measurement per 12-h interval (`run_anchor_analysis.py`); covariate temporal-definition table (`make_supp_table5.py`); **bootstrap CIs** for ΔAUROC, NRI and IDI (`run_deltaauc_bootstrap.py`, `run_nri_bootstrap.py`); **MICE with the outcome in the imputation model** (`run_mice_with_outcome.py`); **5-fold cross-validated internal validation** (`run_internal_validation.py`); **±1-h matching-window sensitivity analysis** (`run_narrow_window.py`); joint VR initial × VR delta prediction surface (`joint_heatmap.py`) |
| 6. Figures | `05_figures/` | Figures 1–6 of the manuscript |

## Environment

Python 3.12; dependencies: `pandas`, `numpy`, `scipy`, `statsmodels`, `scikit-learn`, `matplotlib`, `python-docx`, `Pillow`.

## Outputs

Result tables (CSV/DOCX) and figures (PDF/SVG/PNG/TIFF) are written to the output folders referenced by each script. Key results reported in the manuscript:

- Derivation cohort: 13,145 stays (12,556 unique patients), hospital mortality 19.6%; complete-case fully adjusted analysis n = 10,791.
- External validation: eICU n = 1,324; the harmonized reduced model was fitted in MIMIC-IV and transported unchanged to eICU; the VR–mortality association was additionally re-estimated in eICU (external replication).
